使用说明
  • 这是公开的只读统计页，知道链接的人都可以查看；请不要把页面当作私密后台。
  • 无须 GitHub 登录即可查看。因为网站运行在 GitHub Pages，浏览器需要能访问 CounterAPI 才能更新数字。
  • 访客与事件会受到浏览器广告拦截、网络限制、重复访问及第三方统计服务可用性的影响，不能当作精确人数。
  • 先前版本的历史数据无法恢复；统计页自身不会重复计入游戏访问。
